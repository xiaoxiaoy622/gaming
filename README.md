# TIME WARP — 游戏加速器

## 项目说明

本项目是斗罗大陆 H5 游戏的个人化部署版本，仅包含前端静态资源（HTML / CSS / JavaScript / 图片），**不包含任何后端服务**。所有资源均引用自原始 CDN，部署后即可通过浏览器访问。

**核心特性**：时间加速器（游戏科技风 UI）+ CDN 智能缓存 + 移动端适配

## CDN 缓存方案

本项目实现了智能 CDN 缓存系统，优先从 CDN 加载资源，利用浏览器 localStorage 缓存，**缓存7天后自动过期**，无需手动更新版本号。

### 工作原理

```
访问流程：
1. 检查 localStorage 缓存（含7天有效期）
   ├─ 命中且未过期 → 直接显示（毫秒级，无网络请求）
   ├─ 缓存已过期(>7天) → 自动清除并重新下载
   └─ 未命中 → 请求 CDN
       ├─ 成功 → 显示 + 存入缓存（7天有效）
       └─ 失败 → 降级到本地 img/ 目录
```

### 自动过期机制

| 场景 | 行为 |
|------|------|
| 首次访问 | 从 CDN 下载 → 存入缓存（7天有效） |
| 7天内访问 | 使用本地缓存（无网络请求） |
| 7天后访问 | 自动清除过期缓存 → 重新从 CDN 下载 |
| CDN 不可用 | 降级到本地 img/ 目录 |

### 控制台命令

| 命令 | 功能 |
|------|------|
| `showCacheStatus()` | 查看缓存状态（数量、大小、已缓存天数、剩余天数） |
| `clearAllCache()` | 清除所有缓存 |
| `refreshCache()` | 强制刷新缓存并重新加载 |
| `forceCdn(true/false)` | 强制使用 CDN 或本地资源 |
